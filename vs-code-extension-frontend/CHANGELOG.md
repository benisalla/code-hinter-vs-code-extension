# Change Log

## [0.1.0]

- The tutor: hint ladder (nudge → concept → pinpoint → plan → ask my professor), never the solution.
- Learning profile: level and learning style (examples, analogies, step by step, guiding questions).
- `Test me`: adaptive quizzes on this exercise, everything the professor taught, or weak concepts.
- `Explain a concept`, `Ask the tutor a question`, `Ask my professor`.
- `My learning progress` dashboard; readiness check before the final submission.
- Evaluation panel shows ✔/✘ per concept with hint/explain buttons; all webviews escape their content and follow the VS Code theme.
- `codeHinter.serverUrl` setting; status bar hint button; keyboard shortcuts.
- Removed the code completion that replaced the whole file with AI-generated code.
- Fixed the `Test api's` command (it was registered under a different id); the password is no longer stored.
